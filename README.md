# Invaria Evidence Lab

Live demo: https://paugk.github.io/Lab_web/

A single static page (`index.html`) that checks Invaria's claims against real outputs of its code: testnet evidence, tamper-evident bundles, integrity analytics and controlled disclosure. The engine itself lives at https://github.com/paugk/Invaria (branch `opensource/core-initial`).

No build step. Serve the folder with any static host, or open `index.html` in a browser (needs network access for Google Fonts and `tweetnacl` from cdnjs).
